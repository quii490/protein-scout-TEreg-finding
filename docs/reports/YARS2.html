深度机制分析

结构域架构：YARS2（UniProt Q9Y2Z4，477 aa，52.5 kDa）属于I类氨酰tRNA合成酶（aaRS）家族中的酪氨酰tRNA合成酶。其域架构为Rossmann折叠催化域（IPR001412 - aminoacyl-tRNA synthetase, class I, conserved site；Pfam:PF00579 - tRNA-synt_1）形成核心酶活中心，采用经典的HIGH和KMSKS基序催化ATP依赖的酪氨酸激活和tRNA Tyr氨酰化。C端包含反密码子结合域（IPR002307 - tyrosine-tRNA ligase, C-terminal domain），以α-螺旋束折叠识别tRNA Tyr反密码子GUA。IPR036986（RNA-binding S4 domain）提供tRNA茎环结构的识别平台。IPR002305（aminoacyl-tRNA synthetase, class Ic）定义酪氨酰aaRS亚类，IPR024088提供古细菌型tyrosyl-tRNA synthetase标记。MTS（线粒体靶向序列）引导蛋白定位于线粒体基质。

PPI互作网络：STRING数据显示YARS2嵌入紧密的氨酰tRNA合成酶互作网络——YARS（胞质酪氨酰tRNA合成酶，评分974）、WARS2（线粒体色氨酰tRNA合成酶，评分951）、AARS（丙氨酰tRNA合成酶，评分938）、WARS（胞质色氨酰tRNA合成酶，评分932）、MARS（甲硫氨酰tRNA合成酶，评分927）、NARS2（线粒体天冬酰胺酰tRNA合成酶，评分926）、EARS2（线粒体谷氨酰tRNA合成酶，评分909）和IARS（异亮氨酰tRNA合成酶，评分904）。极高置信度评分提示aaRS在线粒体翻译装置中形成多合成酶复合体。

结构-功能关系：YARS2催化酪氨酸+ATP→Tyr-AMP+PPi的第一步反应，随后将活化的酪氨酸转移至tRNA Tyr 3'-CCA末端。对底物酪氨酸的高选择性是通过催化口袋对酪氨酸侧链酚羟基的氢键识别实现的，错配率极低（编辑域增强保真度）。线粒体定位意味YARS2为mtDNA编码的13个氧化磷酸化亚基的合成提供aaRS服务——这13条多肽包含多个酪氨酸残基，因此YARS2活性对OXPHOS效率至关重要。

TE调控机制：氨酰tRNA合成酶与TE调控的连接通过两个非经典通路。其一，线粒体aaRS的mtDNA翻译功能维持OXPHOS和氧化还原平衡，线粒体功能障碍→ROS→DNA损伤→TE去抑制这一已知级联通路将YARS2功能与核染色质状态连接（Leber遗传性视神经病变研究PMID:42260285提示YARS2突变与该疾病相关）。其二，YARS2在胰腺癌PARP抑制剂抗性中的作用（PMID:42235275 - YARS2 mediates PARPi resistance via MYC-E2F axis）强烈提示aaRS的超越翻译的非经典功能——一些aaRS在特定条件下可穿梭至核内，直接参与转录调控（如EARS2、GARS已有核转录功能证据）。鉴于tRNA衍生小RNA片段（tsRNA/tiRNA）已被证明可调控转座子，YARS2产生的误氨酰化tRNA可能通过tRNA降解通路影响tsRNA的丰度。

前沿意义：YARS2有52篇PubMed文献，主要集中在遗传性眼病（Leber遗传性视神经病变）和癌症PARP抑制剂抗性研究。YARS2的PARPi抗性机制（MYC-E2F轴调控）为TE研究提供了一个高度相关的切入点——PARP1在染色质上识别DNA损伤位点，其功能与ERV/LTR的PARylation依赖性转录调控直接相关。YARS2是否通过非经典核穿梭参与直接TE调控（类似已知的aaRS兼职转录因子功能），是极为原创且可测试的研究方向。
