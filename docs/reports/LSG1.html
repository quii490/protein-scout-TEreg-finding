3.2 蛋白大小评估

658 aa / 75.2 kDa，完美落在 300-800 aa 实验优势区间。作为 GTPase 家族蛋白，其大小适中，结构域紧凑——G domain 清晰可辨。评分: 9/10。

4. 总体评价

推荐等级: ⭐⭐⭐ (3/5)

归一化总分: 72.7/100

定位分类: nucleoplasm

核心优势: 1. 核糖体成熟的关键酶: LSG1 是 pre-60S 最后一步 GTPase，在核糖体生成通路中占据独特位置 2. 结构已解析: Nature Struct Mol Biol 2017 的 cryo-EM 结构提供了 LSG1 在功能状态下的高分辨率快照 3. 极度新颖: 26 篇文献，功能机制研究窗口仍在开放

核心局限: 1. 功能在细胞质: LSG1 的经典功能是细胞质 pre-60S 成熟，核定位(Cajal body)可能反映的是 NPC 转运中间态而非核内功能 2. 非 TE 调控蛋白: LSG1 是核糖体组装 GTPase，与染色质调控/TE 沉默无关 3. PPI 网络极稀疏: 作为 transient assembly factor，缺乏稳定的蛋白互作网络——这是生物学特性但也是筛选维度上的劣势 4. 无调控结构域: MMR_HSR1 是核糖体结合 GTPase，非经典调控域

综合判断: LSG1 是核糖体生物学的"精细工具"——它在 pre-60S 成熟的最后一个检查点起作用。但它不是 TE 调控候选蛋白。虽然 HPA 检测到了核定位信号 (Nuclear bodies, Cajal body)，但其功能本质是细胞质的核糖体组装。nucleoplasm 分类是比较合理的归属（考虑到 HPA 信号），但人工筛选 TE 调控候选时优先级低。
