详细分析

DKFZp686O0870 (Q6AWA4) 与 DKFZp686A111 (Q6AHZ7) 是同一基因 GTF3C1 的不同 cDNA 克隆片段。两者的 UniProt 条目标记为 "Fragment"，均来自德国 cDNA 联盟的克隆测序项目。条目包含相同的 Pfam 结构域 (TFIIIC 亚基特征域) 及 GO 注释 (转录起始、DNA 结合)。

条目被标记为 "Fragment" — 序列 C 端不完整 (non-terminal residue at position 2112)，进一步表明这是一个部分 cDNA 克隆而非全长蛋白。

与 DKFZp686A111 的关系

两者均映射至 GTF3C1 (Q12789, Swiss-Prot)，是同一基因的不同 cDNA 克隆片段。DKFZp686A111 (2,109 aa) 和 DKFZp686O0870 (2,112 aa) 的长度接近但略有差异，反映了不同克隆的测序覆盖范围差异。

处理建议

与 DKFZp686A111 一致，此条目应替换为正式基因符号 GTF3C1 (Q12789)，进行独立评估。

最终判定: REJECTED (与 DKFZp686A111 为同一基因 GTF3C1 的重复 cDNA 克隆条目)
