3.6 PPI 互作网络

已知复合体:

  • PRC1-like complex — L3MBTL2 是 PcG 蛋白, 参与 H2AK119ub1 介导的染色质沉默
  • Histone interaction — MBT domain 直接结合 H3K9me2/me3 和 H4K20me1/me2
  • Chromatin condensation — 通过压缩核小体阵列实现稳定转录抑制

评价: L3MBTL2 不依赖传统的大规模 PPI 网络——它的核心功能通过 MBT domain 直接读取组蛋白甲基化标记 来实现, 而非蛋白质-蛋白质相互作用网。这是与 MAK16/LSG1 等 ribosome 蛋白的本质区别——L3MBTL2 的功能机制是"chromatin reading"而非"complex assembly"。评分: 8/10（功能机制清晰, PPI 量不重要; MBT domain 直接读取 histone marks）。

核心优势: 1. Polycomb 染色质调控因子: L3MBTL2 是 PcG protein, 通过 MBT domain 直接读取组蛋白甲基化标记 (H3K9me, H4K20me) 2. 与 TE 调控直接相关: PcG proteins 是 TE 和重复序列沉默的关键因子——L3MBTL2 通过 H2AK119ub1 和染色质压缩参与这一过程 3. 结构功能完美匹配: 2×MBT domain + ZnF → 所有域指向 chromatin binding 4. ChIP-Seq 实验验证: ENCODE WT=2, ChIP-Atlas 归类为 TFs/others

核心局限: 1. 无独立 PDB 实验结构: 需要依赖 AlphaFold 预测 2. 文献量适中: 33 篇, 不如极度新颖 (<10篇) 但高于过于成熟 (>100篇) 3. PPI 非传统网络型: PPI 通过 histone 互作而非大型蛋白复合体——在评估框架中需要特别说明

综合判断: 这是本批评估中第一个真正的 TE 调控核心候选。L3MBTL2 不是另一个核糖体蛋白——它是 Polycomb group 染色质沉默因子, 通过 MBT domain 直接读取组蛋白甲基化标记, 参与异染色质形成和转录抑制。与 MAK16、LSG1、RRP9 等核糖体生成蛋白不同, L3MBTL2 的功能与 TE/重复序列的染色质沉默直接相关。chromatin 分类, TE 调控优先级高。
