4. 总体评价

推荐等级: ⭐⭐⭐ (3/5)

归一化总分: 73.8/100

定位分类: nucleolus

GTPBP4 是核仁 pre-60S maturation GTPase——与 LSG1 和 MAK16 功能主题一致。GTPase 活性+核仁定位+NPM1互作使其有适度调控潜力, 但核心功能仍是 ribosome biogenesis。推荐 nucleolus, TE 调控优先级低。

与 LSG1 对比: GTPBP4 (73.8) 和 LSG1 (72.7) 是核糖体 GTPase 姐妹蛋白, 功能高度相似。GTPBP4 的 HPA 信号更强 (Supported vs Uncertain) 和 AF pLDDT 更高 (81.4 vs 69.4) 略微拉开差距。
